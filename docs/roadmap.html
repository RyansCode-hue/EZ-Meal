Open decisions

  1. Which capture model should EZ Plan follow?

    Each one leads to a different inbox and task layout.

    CODE

    1. Capture
    2. Organize
    3. Distill
    4. Express

    Building a Second Brain. Steps for handling what you save.

    PARA

    1. Projects
    2. Areas
    3. Resources
    4. Archives

    The same author's four places to file things.

    GTD

    1. Capture
    2. Clarify
    3. Organize
    4. Reflect
    5. Engage

    Getting Things Done. Five steps, built around an inbox and next actions.

  2. When should Android builds resume?

    Phase 9 assumes soon, once the website feels stable.

  3. When to buy the Apple Developer account?

    It gates the iPhone app in Phase 11.

  4. Should chat history be per phone or shared?

    Shared means either of you can pick up a conversation the other started.
